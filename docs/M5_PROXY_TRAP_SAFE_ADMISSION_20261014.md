# Offline M5 synthetic input: reject Proxy and revoked Proxy objects before traps

**Scope**: isolated product-core 1/2 [issue #2348](https://github.com/Zennay/Supa/issues/2348), based on frozen hosted-green [DRAFT #2344](https://github.com/Zennay/Supa/pull/2344), SHA `fc21a87748f93f54fcb21323b26bbac20d098e46`, [CI #38514268634](https://github.com/Zennay/Supa/actions/runs/38514268634) 1,266/1,266 Node PASS, high audit 0, M1 matching/source-permission and build all green.

The exported pure `compareInspections` / `captureShape` APIs receive *synthetic inspection objects*, not browser or source data. Prior safeguards read only own descriptors, but on a JavaScript `Proxy`, even `Object.getOwnPropertyDescriptor` can execute a custom trap. Reading an array's `.length` or testing `'parseError' in record` can likewise run Proxy `get`/`has` handlers. A **revoked Proxy** can throw a raw runtime TypeError even through `Array.isArray`. These hostile inputs are not canonical outputs of the M1 HTML inspector. The vulnerability concerns untrusted direct in-memory callers, not any observed retailer issue.

**Product change:** use Node's trap-free `util.types.isProxy` to refuse Proxy-wrapped current/baseline cohort envelopes, their `sources` arrays, individual inspected source objects, HTML roots, JSON-LD and application/json arrays, nested rows and type/key arrays, and Schema.org decision/observation objects *before any caller object reflection or length read*. The existing failure contracts remain opaque and context-sensitive: current or historical cohort, inspected source, HTML shape, or Schema.org decision. Own plain M1 objects continue through the original Product/abstain pipeline; P1/P2/P3 remain **human review only**. No source rights, selectors, production, or M5 release is authorized.

**New synthetic tests:** 32 direct tests on hostile `get`, `getOwnPropertyDescriptor`, `ownKeys` and `has` traps plus revoked Proxy wrappers at each trust boundary, expected generic errors and zero handler invocations. Positive tests preserve fictional Product observation, separate-history manual P3, missing-history P2, failed/removed P1, same-object baseline rejection and false rights/selector/production/M5 gates. There is no retailer network access, real capture, observed price, consumer data or scrape authorization.
