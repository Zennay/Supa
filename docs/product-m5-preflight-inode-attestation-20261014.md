## Gap
The existing M5 reader takes SHA-verified private snapshots from opened root/store/file descriptors and maintains root/store handles for the full cohort, but those handles were not compared to the physical inodes checked by earlier `requireRegularCaptureTree` preflight. An independently constructed regular source directory or source file with byte-identical and SHA-identical content could be substituted **between preflight and opening**; SHA alone does not prove nominated tree ownership.

## Narrow product correction
`requireRegularCaptureTree` now returns an in-memory bounded identity: original capture root `(dev,ino)`, one supermarket `(dev,ino)` per successful store and one HTML `(dev,ino)` per successful `<store,NUL,source-id>` pair, in addition to the already-enforced symlink, hardlink, source/HTML size, 8MiB aggregate and path grammar controls. Both current and historical preflight identities are passed privately to the frozen inspection stage. `withPinnedCaptureTree` checks its newly opened root and store descriptor identities against earlier preflight facts, while `readVerifiedHtml` checks the final opened O_NOFOLLOW file inode against its original preflight identity **before reading source bytes**. Missing proof entries refuse the whole capture. Original SHA, 64KiB reads, 8MiB byte budget, fatal UTF-8, P1/P2/P3, unchanged canonical M1 inspector, anonymous CLI and cleanup remain in place. Direct synthetic helper's optional preflight argument stays optional to preserve original test seams; the production `compareCaptureDirectories` now always supplies a full expected identity for both sides.

## Owned synthetic evidence
`tests/product-m5-preflight-inode-attestation-20261014.test.mjs` adds ten local-only tests: matching real initial inode positive control; same-byte and SHA-equal HTML inode replacement after early proof; same-byte *ordinary* store-directory replacement; entire *ordinary* root replacement; missing HTML proof; forged root and store proof; independent two-source P3; unavailable P1 without HTML; anonymous P2 CLI without origin/private path leaks. No live store requests, prices, personally identifiable user data or privileged filesystem attack behavior.

## Explicit remaining limits and gating
This binds the earlier lstat identity to the later open descriptor under ordinary post-preflight path substitutions. It is not an atomic or immutable original file-content transaction under privileged concurrent writes to the same inode, not a defense against same-UID changes to private temp files or a global source licensing/reliability proof.
