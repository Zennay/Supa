# M3 observed-basket evidence

This directory is reserved for **durable, converted `WeeklyBasketStudy` JSON evidence** from the genuine M3 field run.

## Allowed here

- privacy-safe converted study JSON produced by `npm run m3:build-observed-study`;
- small Markdown documentation that explains the evidence contract.

## Keep out of Git

Do not commit raw collection sheets, receipt/cart screenshots, PDFs, photos, exported account files, names, email addresses or other direct participant identifiers here.

Raw collection templates and generated assessment reports belong under `artifacts/m3/`. Those files are operational output, not canonical evidence.

A committed study is not automatically a public savings claim. Better, same, worse and unknown outcomes all remain valid evidence, and a single observed week must not be generalized beyond its measured context.
